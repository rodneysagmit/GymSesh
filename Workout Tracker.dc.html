How to use this tracker
Before: fill in date, time, gym, focus, energy, warm-up.
During: after each set, log weight, reps, rest, RPE right away — add sets/exercises as you go.
After: fill in cardio, stretching, PRs, pain notes, and a one-line summary. Tap Copy and paste into ChatGPT to review progress.
Tips to improve over time
Keep RPE on the same 1–10 scale every session so trends are comparable. Log body weight weekly, not daily. Save a copy of each session (screenshot or pasted text) so ChatGPT can compare across weeks. Only add fields you'll actually fill — an unused field slows you down more than it helps.
